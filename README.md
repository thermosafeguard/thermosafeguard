# ThermoSafeguard

CPU temperature monitoring and automatic thermal control for Windows 10/11 (64-bit).

[Official website](https://thermosafeguard.com/) · [Features and plans](https://thermosafeguard.com/en/) · [Official Windows download](https://api.thermosafeguard.com/downloads/ThermoSafeguard-Setup.exe)

ThermoSafeguard monitors CPU temperature and can temporarily regulate CPU performance as heat rises, restoring performance as it cools. Graphs show temperature and CPU activity together.

| Permanent Free plan | Optional Pro subscription |
| --- | --- |
| Local use without an account or subscription | All Free features |
| CPU temperature monitoring, graphs, sensors and logs | Four selectable thermal ranges |
| Automatic regulation using the most conservative thermal range | Use on up to two devices |
| CPU Cooler Booster on compatible hardware | Recurring subscription; see the official site for current prices |

The current Windows installer is unsigned. Sensors, fan control and manufacturer charge limits depend on hardware compatibility.
